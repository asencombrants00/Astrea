# Astrea — Le Royaume des Étoiles

Page d’accueil statique basée sur la référence visuelle fournie.

## Comportement

- l’image source n’est pas modifiée ;
- son ratio original `393 × 310` est conservé ;
- toute l’interface reste visible, y compris les quatre boutons du bas ;
- aucun recadrage ni étirement n’est appliqué ;
- des marges de fond peuvent apparaître lorsque le ratio de l’écran diffère de celui de la référence.

## Lancer localement

Ouvrir `index.html` directement, ou lancer un serveur local :

```bash
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.
